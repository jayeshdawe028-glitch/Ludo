# LudoCord

Discord Embedded Activity MVP for a lightweight 2–4 player Ludo game.

## Planned stack
- Discord Embedded App SDK
- React + TypeScript + Vite
- Node.js + Express + Socket.IO
- SQLite
- Discord slash commands

## Commands
- `/flex` — show the current player's lifetime games, wins and losses
- `/help` — show all commands
- `/check @user` — show another player's lifetime stats
- `/invite` — show the bot invite URL placeholder
- `/community` — show the Discord community URL placeholder

## Activity
- LudoCord loading screen/logo
- Hamburger menu with Music, Sound Effects and Donate
- Donate URL: https://ko-fi.com/alwaysjake28
- Player stats in the header
- Play with Channel Friends
- Play with Random World matchmaking
- Maximum 4 active players; extra viewers become spectators

## Configuration
Copy `.env.example` to `.env` and fill in Discord/bot and server settings.
